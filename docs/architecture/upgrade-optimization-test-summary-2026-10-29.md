### 2.5 只修剩下的两题

`paper-25-1` 不另开论文专用规则。

**总览。** `paper-theme` 走的是目录，不是检索。`knowledge.catalog` 用整句「三篇论文各自讲什么」做标题子串过滤，目录被滤成 0 条。放宽之后，模型仍因「只有标题、没有正文」拒答，答案门禁再把拒答打回去重试，单题被拖长。最后改为：总览题直接按标题归纳，切片标题（如「（1/15）」）并成一篇，不再调用成文模型。

**超时。** `paper-step-1` 的第一跳已经有证据，下一步却继续等规划或长推理，直到运行截止；失败还会被 JetStream 重新投递，客户端才看到约 300 秒超时。改为：已有证据就直接成文；规划与成文各自有短于 300 秒的上限；截止类失败不再反复投递；成文关闭长推理，避免思考过程占满预算后仍然没有正文。

### 2.12 按篇有界成文与完整留证

不再按篇名是否出现来追加一次自由补写。内容总览按当次目录计划逐篇使用自己的补读证据成文，校验后组合；任一篇缺补读证据、空输出、非中文短段、句尾不完整或遗漏证据中的参数规模型号时明确失败。模型名称由正文提取，不写固定论文答案；普通连字符词和背景型号不全部强制输出。校验检测机械完整性，不自动证明语义关系正确。

每篇最多 600 输出 token，最多三路并发，仍共用原 35 秒成文截止。日志记录分篇耗时、输出量和错误/context 终止；当前接口不能提供真实的上游 finish_reason。测试脚本保存完整答案、当次问法、耗时、错误和终态事件，并加回 `scp-reject-2`。当前共 24 题（额外包含目录题 `paper-list`），部分问法不同于原基线，明确标为升级回归，不作为原 S1 验收。

- `20261102T071751421671Z_gate.json`：总览命中，约 14.7 秒。
- `20261102T071837583148Z_full.json`：同一轮 24 题自动评分 SCP 可答 9/9、论文可答 10/10、拒答/隔离 5/5。总览约 17.6 秒。
- `20261102T072324581433Z_gate.json`：独立总览再测命中，约 8.4 秒。

### 2.13 统一完成状态、答案提交与冻结评测流程

普通成文改为缓冲候选，完成模型流后交给现有门禁，之后才提交正式正文；门禁拒绝后的安全替代回复不再调用模型重写。生成异常不再因已收到部分正文而返回成功；截止、取消、其他生成失败分别报告对应终态。非空答案不能提前绕过空证据、版本冲突和既有来源硬约束；跨语言词面重叠仍仅用于诊断，门禁不等于全部语义事实验证。

Gateway 透传上游结束原因；Core 能识别 length/content_filter、流内错误和无终态 EOF。Gateway 已输出增量后不再拼接备用模型；队列不对已结束的模型协议或最终成文失败反复重投同一 Run。通过结构化行为接口传递该标记，避免队列依赖 LLM 客户端实现造成导入循环。

冻结清单 `upgrade_regression_v1.json`，保存清单快照、逐次尝试、源码与本地镜像指纹；支持离线重评和最多两次不改写客户端重试。参数错误或运行中环境变化返回 2，存在失败返回 1，全通过返回 0。当前清单明确不是原题集 S1。

### 2.14 尾延迟诊断、保守路由与有界竞速候选

将简单短概述与带必保型号的概述分开选层：开发环境简单概述用快层，型号篇与普通问答保留复杂模型，生产默认复杂模型。保留全部原文，仅前置型号定义块；规范纯正文空白，不丢背景、不降低名称校验。增加逐篇首正文时间、增量间隔、输入量与实际路由日志，以及保留所有失败样本的重复对照工具。

无竞速路由版本完整回归 `20261102T094217200092Z_full.json`：24/24 自动评分通过，全部完成，流式错误 0，`run_valid=true`；但总览仍达 **18.98 秒**，普通复杂问答也出现约 24–29 秒成文。这说明路由并未稳定解决长尾。

新增绝对耗时触发的有界竞速候选：默认关闭、开发测试 4000 ms；每个总览最多一个额外请求、每 Core 进程同时最多两个额外请求。每个候选独立完成同样校验，先通过者提交、取消败者，共享原截止，不拼接内容，不重试触发前已失败的请求。

定向五次记录 `20261102T094748653361Z_tail_benchmark.json`：5/5 通过，平均 5,070 ms、中位 3,688 ms、观测最大 10,251 ms；同为五次、10 秒轮间隔的无竞速基线为 7,815 / 8,229 / 11,923 ms。额外请求两次均由原请求先完成，备份取消，故不能把整批变快归因于竞速，也不能推导 P95。复杂模型长尾、备份收益和实际 token 成本仍需持续采样。

最终候选完整回归 `20261102T095218100334Z_full.json` 为 **24/24**（SCP 可答 9/9、论文可答 10/10、拒答/隔离 5/5），全部收到完成事件，流式错误 0，源码/清单/本地镜像未在运行中变化，`run_valid=true`。总览约 **2.58 秒**，没有触发竞速；与上一版本 18.98 秒均保留，不能用单次下降证明 P95 或备份收益。Core 相关包 race 测试及 Python 11 项测试通过。

全快层、删背景、空闲竞速、批量合成及一次自动纠正的失败/不足记录均保留，未用快速失败冒充性能收益。代码与测试、回退方式、全部实验表见[尾延迟优化记录](tail-latency-optimization-2026-11-02.md)。这些成绩不是原题集 S1，也没有验证新入库恢复或生产容量。
