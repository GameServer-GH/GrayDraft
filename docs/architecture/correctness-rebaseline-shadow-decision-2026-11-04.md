## 离线纠错的实现与历次回放

固定基线的三个归档场景和四个受控对照通过独立回放工具验证。工具先调用现有 Go 声明复核器，再独立复算数值记录。复核 Agent 通过本地 Gateway 读取问题、候选和同一份可见证据，返回保留、一次修订或证据不足。修订采用摘录式输出。程序按片段序号和行号提取原文，校验范围和摘要，再用同一份证据运行 Go 复核和独立的用例断言。证据不足是闭环的终止状态，可附上已支持的部分。

归档候选先校验摘要。证据回放仅从冻结快照还原已记录的可见范围，并逐段校验摘要。M87 的旧拒绝只留下运算依据，因此用这些操作数构造错误候选，验证的是同一类错误的纠正。回放使用重建的观测编码和现有门禁中的声明复核能力。独立断言针对七个样例，无法衡量一般语义蕴含。
