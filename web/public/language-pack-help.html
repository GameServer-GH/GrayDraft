GrayDraft 语言包插件规范

本文档描述前端如何校验并加载 kind: "language-pack" 插件。实现细节见源码：src/locale/schema.ts（词条键列表与 validateLocaleMessages）、src/locale/resolve.ts。

1. Manifest 要求

  • kind 必须为字符串 language-pack。
  • localeTag（或后端 manifest 中等价字段）为 BCP 47 标签，例如 zh-CN、en-US，用于设置 document.documentElement.lang。
  • 必须携带 messages 对象：键为下表所列全部词条 id，值为非空字符串。缺少任一键、类型非字符串、或值为仅空白，校验失败，前端将拒绝启用该语言包或拒绝切换。

2. 占位符

以下键的值中可包含占位符 {name}、{handle}，由运行时替换：

  • agentDock.removeFileAria — {name} 为文件名。
  • notebookCard.resizeAria — {handle} 为 n、s、e、w、ne、nw、se、sw。

4. JSON 示例（节选，正式包须含全键）

{
  "kind": "language-pack",
  "id": "lang-en-us",
  "version": "1.0.0",
  "localeTag": "en-US",
  "messages": {
    "settings.title": "Settings",
    "workspace.newNotebook": "New notebook"
    /* …其余键与 zh-CN 内置包对齐 … */
  }
}

5. 行为说明

  • 在插件页启用语言包前，会运行 validateLocaleMessages；不通过则开关不会打开。
  • 在设置 → 通用打开「使用语言包」时，须至少有一个已启用且校验通过的语言包。
  • 界面语言下拉仅列出满足上述条件的语言包。
  • 关闭「使用语言包」后，界面使用环境变量 VITE_DEFAULT_LOCALE 对应的内置文案（当前支持 zh-CN、en-US，其余回退 zh-CN）。
